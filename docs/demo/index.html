Decode a real forearm, in your browser

This page runs the myobridge Python library itself (via Pyodide) on real recordings from the 3DC dataset. It calibrates on one part of a person's session, then streams the rest through the live pipeline 20 samples at a time, exactly as packets arrive from the armband. Break an electrode while it plays and watch the quality monitor catch it.

Setup

The first run downloads Python, NumPy and SciPy (your browser caches them) and about 7 MB of recordings.

What you're seeing

  • The model is LDA on 15 features per electrode, trained on the person's first two cycles through the 11 gestures (about 2 minutes of data). It then decodes their first cycle of the second half of the session, which it never saw.
  • An electrode coming off or clipping makes the decoder drop that channel and carry on with the others, using the same model minus that electrode's features. Mains hum and motion are flagged but kept, because the filters already remove most of them.
  • The trace shows the raw signal, before filtering, which is what the monitor looks at.

Recordings: 3DC dataset, Côté-Allard et al., Frontiers in Bioengineering and Biotechnology 8:158 (2020), as mirrored by the LibEMG project. Your browser loads them directly from that repository; this site doesn't host a copy.
